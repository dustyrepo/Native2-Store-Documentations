How this site is organized

Each script has its own page with the same structure, in the order you'll actually need it:

  • Dependencies - what has to be installed and started first.
  • Installation - the exact steps to get it running.
  • Configuration - every config key, its default, and what it controls.
  • Commands and Exports / Events - what players and other resources can trigger.
  • Notes - gotchas and edge cases worth knowing before you rely on the script in production.
Scope: n2-recoil, n2-knockout, n2-chat, n2-laptop.
